# JobMaxxing 🚀

> Stop applying. Start maxxing.

**JobMaxxing** is an AI-powered job portal built for Indian developers. We match candidates to the right roles based on actual skills — not just keywords — using GitHub profile analysis and Claude AI.

---

## What makes us different

- **GitHub-verified skills** — your repos speak louder than your resume
- **AI match scoring** — every job gets a 0–100 fit score tailored to you
- **India-first** — INR salaries, tier-2 city support, Razorpay payments
- **Zero spam** — no irrelevant recruiter calls, no keyword-stuffed JDs
- **Built-in ATS** — companies manage their entire hiring pipeline in one place

---

## For candidates

- Sign in with GitHub — profile auto-fills from your repos
- See jobs ranked by how well they match your actual skills
- AI resume builder, cover letter generator, interview prep
- Real salary data for your skill set and city

## For companies

- Post a job — AI parses your JD automatically
- Get a ranked list of matched candidates instantly
- Built-in kanban pipeline (Applied → Screened → Interview → Offer)
- Bulk outreach via email and WhatsApp

---

## Tech stack

- **Frontend** — Next.js 14, Tailwind CSS, shadcn/ui
- **Backend** — Node.js, Supabase (PostgreSQL + Auth + Storage)
- **AI** — Claude API (matching, parsing, personalization)
- **Payments** — Razorpay
- **Infra** — Vercel, Railway, Redis
