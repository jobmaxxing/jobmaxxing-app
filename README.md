# 🚀 JobMaxxing

**JobMaxxing** is the ultimate, all-in-one career acceleration and job search optimization platform. Tailored for software engineers and modern professionals, it serves as a central dashboard to track applications, optimize digital presence (LinkedIn, GitHub, Resume), prepare for interviews, and execute high-converting recruiter outreach.

---

## 🗺️ Application Map & Navigation

JobMaxxing is structured around a central app shell with dedicated dashboards and workspaces. Here is a breakdown of the available routes and sections:

### 🏠 Landing Page
*   **Root Route (`/`)**: Introduces JobMaxxing's suite of features, core value propositions, and direct navigation links to the application environment.

### 💼 Main Workspace (`/app/...`)
All major features live under the `/app` path, managed by a cohesive app shell layout:

*   **📊 Dashboard (`/app/dashboard`)**: The primary command center. Monitors key application metrics, upcoming tasks, interview schedules, and provides quick shortcuts to the various optimization modules.
*   **📄 Resume Analyzer (`/app/resume`)**: Tailors your resume to target job descriptions, identifies critical keyword gaps, and helps polish formatting.
*   **🤖 ATS Scanner (`/app/ats`)**: Predicts your Applicant Tracking System score by parsing resume content against job specifications.
*   **🔗 LinkedIn Optimizer (`/app/linkedin`)**: Audits your LinkedIn profile sections (headline, summary, experiences) to maximize recruiter search hits.
*   **💻 GitHub Profile Analyzer (`/app/github`)**: Scrapes and analyzes your GitHub profile to optimize repositories, pinning strategies, and commit impact metrics.
*   **📂 Portfolio Builder (`/app/portfolio`)**: A sandbox to design, preview, and build personal developer portfolio sites.
*   **📅 Interview Simulator (`/app/interviews`)**: Provides target question lists, behavioral prep trackers, and notes to ace tech interviews.
*   **✉️ Cold Email Outreach (`/app/cold-email`)**: Drafts high-converting, template-based and personalized cold emails to recruiters and hiring managers.
*   **📋 Kanban Job Tracker (`/app/job-tracker`)**: Track application statuses from "Applied" to "Offer" with task lists, contacts, and key follow-up dates.
*   **⚙️ Settings & Profile (`/app/settings`, `/app/profile`)**: Manage personal career details, API integrations, and application configurations.

## 🛠️ Tech Stack & Architecture

*   **Frontend Library**: React 18 with Vite
*   **Routing**: React Router DOM (v6)
*   **Styling**: Modern CSS coupled with Tailwind CSS for layout systems
*   **Deployment**: Optimized configurations for Vercel integration (`vercel.json`)
